BTCUSDT｜CPI 前流動性劇本

2026-10-14 · 20:30 CPI 前 · BTC 約 83.4K

關鍵中樞83,400
核心假設

短線可能先掃 82,600 下方流動性，快速收復後利用上方空單清算作燃料，依序逼近 84,500 → 87,368；若突破前高，可能進入 90,000–94,000 週線看跌訂單塊，再觀察是否形成中期反轉與下殺。

20:30

美國 CPI 公布

不預判第一根消息 K。優先看「掃流動性後能否快速收復」與「突破後是否站穩」。

從證據到交易劇本
01
大級別動能轉弱

日線 MACD 死叉、疑似頂背離；3 日 MACD 進入死叉，代表反彈動能正在降溫。

→
02
但週線尚未全面轉空

週線 MACD 仍偏多、且已突破下降趨勢線；因此「先延伸一段上漲再轉空」仍合理。

→
03
上方有可利用流動性

熱力圖顯示 84.5K 一帶清算集中，87K–88K 亦有更高週期流動性。

→
04
最理想路徑

先掃 82.6K → 快速收復 → 逼空 84.5K → 攻前高 87.368K → 90–94K 週線供給。

失效條件

  • 跌破 82,600 後，15m/1H 無法快速收復。
  • 反彈無法重返 82,600，形成 lower high。
  • 80,000–81,000 失守且成交量放大。
  • 進入 90–94K 後若「沒有」看跌結構，不提前硬空。

情境樹

用價格行為確認，不用故事硬套
主劇本

掃低 → 逼空 → 週線供給

82.6K 假跌破並快速收復 → 84.5K → 87.368K → 90–94K。到供給區後再等待 4H / 1D MSS。

替代 A

不掃低，直接逼空

消息偏多或現貨買盤強，價格不回 82.6K，直接突破 84.5K。若回踩守住，仍可延伸到前高。

替代 B

跌破支撐，直接走弱

82.6K 跌破後無法收回 → 80–81K → 75–77K。此時「先逼空到 90K」劇本失效。
